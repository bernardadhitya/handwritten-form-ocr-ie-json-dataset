Chinese Hamster Ovary (CHO) Assay

Spontaneous Mutations in Control Cells

Basic Design:

1. Grow control cells following same procedures as treated cells with the exception that they are not treated with experimental compound

2. Plate 2 x 10^5 cells (approximately) in medium which selects for mutants

3. Count up # of mutants per plate, i.e. there are replicate plates (Xi) per experiment and across experiments

4. To check on survivability, plate 200 cells in standard growth medium & count # which survive; this is also replicated (Pj) for each experiment

5. Standard calculations (computed for each assay experiment)
   1. mean # of mutants per plate:  R (1/R) Σ Xi = M̄
   2. plating efficiency: (1/200·s) Σ Pj = PE
   3. mutants per 10^6 survivors = (MM · 10^6) / (2 x 10^5)(PE)

i.e. if PE = 1.0, then mutants per 10^6 survivors equals 5.0 x mutants per 2 x 10^5 survivors (= a plate)
